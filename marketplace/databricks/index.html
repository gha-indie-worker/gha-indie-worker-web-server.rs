Integration details

Permissions, data flow, and removal

Databricks forwards the signed-in user's token through its trusted application proxy. Only that caller's SQL warehouse and approved view access is used; no service-principal fallback. The token is neither returned to the browser nor stored by this adapter. Do not expose this backend outside the managed Databricks Apps ingress.

Query: bounded SELECT of run identifiers, repository, exact commit, workflow, reported status, timestamp, duration, and profile. No runner control, mutation, installation telemetry, or deployment authority.

To remove access: revoke the app's user consent or view/warehouse grant, then stop or remove the app in the platform. This page does not change permissions.

Databricks package: development source; live installation verification pending. Snowflake Native App: separate delivery track, not installed or published by this package.
